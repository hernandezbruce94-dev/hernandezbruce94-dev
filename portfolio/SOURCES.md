# Primary references

Reviewed October 29, 2026. The sources provide framework and product context; the fictional scenarios, acceptance targets, matrices, and project concepts are proposed designs. These links are not endorsements or proof that a sample satisfies a framework.

| Topic | Source | Use here |
|---|---|---|
| Control assessment | [NIST SP 800-53A Rev. 5](https://csrc.nist.gov/pubs/sp/800/53/a/r5/final) | Assessment planning and separating evidence methods from conclusions |
| Enterprise patch management | [NIST SP 800-40 Rev. 4](https://csrc.nist.gov/pubs/sp/800/40/r4/final) | Patching includes verification, alongside planning and deployment |
| Incident response | [NIST SP 800-61 Rev. 3](https://csrc.nist.gov/pubs/sp/800/61/r3/final) | Response and recovery as part of risk management; not a claim of a complete response playbook |
| Threat modeling | [OWASP Threat Modeling Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Threat_Modeling_Cheat_Sheet.html) | System model, threats, responses, and review |
| Logging | [OWASP Logging Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html) | Sensitive-field handling and testing logging failure paths |
| Azure RBAC scope | [Microsoft scope overview](https://learn.microsoft.com/en-us/azure/role-based-access-control/scope-overview) | Scope hierarchy and inheritance; Azure-specific behavior |
| Azure least privilege | [Microsoft RBAC best practices](https://learn.microsoft.com/en-us/azure/role-based-access-control/best-practices) | Narrow roles and scopes |
| Entra role scope and duration | [Microsoft Entra role best practices](https://learn.microsoft.com/en-us/entra/identity/role-based-access-control/best-practices) | Permission, scope, and duration; distinct from Azure resource RBAC |
| Backup testing | [CISA StopRansomware Guide](https://www.cisa.gov/sites/default/files/2023-10/StopRansomware-Guide-508C-v3_1.pdf) | Backup protection and recovery testing |

Product behavior can change. Check the exact version, identity model, and deployment context before implementation. No vendor commands are claimed tested in these guides.
