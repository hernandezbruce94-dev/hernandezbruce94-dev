# Evidence review checklist

Use for a bounded claim, not as a compliance certification.

- [ ] Requirement, control, and actual tested scope are explicit.
- [ ] Preconditions and the relevant policy/product version are recorded.
- [ ] Expected and observed results are separate.
- [ ] An allowed path and a relevant denied or failure path are covered.
- [ ] Date/time, correlation method, and test method are recorded.
- [ ] Evidence can be located and reviewed by the intended reviewer.
- [ ] Secrets and private data are removed from shared copies.
- [ ] Missing telemetry is labeled inconclusive.
- [ ] Scope limitations, untested dependencies, and exceptions are visible.
- [ ] Owner and review date reflect the actual decision.
- [ ] Configuration changes since observation have been assessed.
- [ ] Closure is based on observed results, not a populated form alone.
